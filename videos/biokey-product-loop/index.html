Frequently asked questions

What is the AmbiSecure BioKey?

A USB security key with an on-device fingerprint sensor, so user verification happens on the authenticator itself rather than through a PIN typed on the host.

Where is the fingerprint stored?

In the secure element on the key. Matching happens on the device and the template never leaves it, so there is no central biometric database to breach.

What does the biometric replace?

The PIN, not the cryptographic key. It is the user-verification step that unlocks the credential; the private key itself never leaves the secure element either way.

What happens if the sensor fails to read?

The key falls back to PIN verification, which is why a PIN is still enrolled during setup. A biometric that cannot be read must never mean an account that cannot be reached.

Does the fingerprint work across different computers?

Yes. Verification is performed by the key, so it behaves identically on any host without drivers, enrolment, or per-machine setup.
